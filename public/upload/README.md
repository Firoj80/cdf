# City Dental & Face Hospital - Image Asset Guide

All section images for the website are cataloged here. You can directly replace any image with your own clinic photos.

### 💡 How To Replace Images
1. Save your replacement photo into `public/upload/` using the exact filename below (e.g. `doctor1.jpg`).
2. Or paste into root `upload/` and run `npm run sync-images`.
3. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.
